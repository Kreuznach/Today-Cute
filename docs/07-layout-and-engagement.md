## 1. 화면에 꽉 차는 콘텐츠

### 원인 (문서·코드 검토)

v0.2.2에서 `.screen`을 `h-full`로 바꿔 viewport 높이는 맞췄지만, **안쪽 콘텐츠가 고정 크기**라 긴 폰에서 아래가 비었다.

| 화면 | 비는 이유 |
|------|-----------|
| Home | 상태 카드가 `p-4` 고정. `flex-1`은 빈 여백만 늘림 |
| Draw | `DrawBox`가 `w-64 h-80` 고정 |
| Result / Final | `CuteCard`가 내용 높이만큼만 차지 |
| History / Collection | 리스트/그리드라 상대적으로 덜함 |

`App`의 `max-w-md mx-auto`는 미니앱(375~430px) 기준으로 유지하는 것이 맞다. 가로 풀블리드는 태블릿/데스크톱 프리뷰에서만 이질감이 난다.

### 이번 반영 (직접 수정)

- 홈 히어로 카드: `flex-1 min-h-[168px]`로 **남는 세로를 카드가 흡수**
- 뽑기 박스: 고정 `h-80` 제거 → 부모 높이를 채우되 `max-h-[360px]`
- 결과/최종 카드: `fill` prop으로 메시지 영역이 남는 높이를 사용
- flex 자식에 `min-h-0`을 넣어 WebView에서 높이 계산이 깨지지 않게 함
- 홈은 짧은 기기에서만 `overflow-y-auto`

### 아직 하지 않은 것 / 다음 후보

- **다크모드**: INTRODUCTION은 다크 기준인데 실제 UI는 라이트(`#F9F9F9`). 심사 전 토스 내비바와 톤을 맞출지 결정 필요
- **실제 캐릭터 일러스트**: 이모지+그라디언트는 번들은 가볍지만 “가득 찬” 인상은 약함. `public/assets/characters/` 가이드는 [05-apps-in-toss-checklist.md](05-apps-in-toss-checklist.md)에 있음
- **Toss 내비바 높이**: AIT WebView가 상단바를 따로 쓰면 `h-full` + safe-area가 이중 여백이 될 수 있음. 실기기에서 확인

## 2. 유입 · 흥미 — 이번 반영

MVP 코어(하루 1장, 광고 재뽑기 1회)는 건드리지 않고, **이미 있는 데이터만으로 홈을 더 두껍게** 만들었다.

| 요소 | 목적 | 구현 |
|------|------|------|
| 요일 인사 | 매일 다른 첫인상 | `getTodayGreeting()` |
| 연속 방문 일수 | “내일도 와야지” | `getDrawStreak(history)` — 보상/포인트 없음 |
| 7일 말랑 도장 | 주간 루틴 가시화 | `WeekStampRow` |
| 컬렉션 미리보기 | 미획득 `❓`로 도감 호기심 | 홈 하단 6칸 |

문구는 “연속 N일째 카드를 받았어요”처럼 **출석 보상·확률 업이 아님**을 분명히 했다.

## 3. 아이디어 백로그 (아직 미반영)

우선순위는 **습관 → 수집 욕구 → 공유/바이럴** 순. 재산상 이익·확률 조작은 제외.

### A. 습관 (재방문)

1. **내일 리마인더 카피만**  
   최종 화면의 “내일 다시 뽑을 수 있어요”를 요일/캐릭터별로 바꿔도 푸시 SDK 없이 잔존율을 조금 올릴 수 있다.  
   실제 푸시는 v0.3.x ([PROGRESS.md](PROGRESS.md)) — 심사·권한 이슈가 있어 지금은 카피만 권장.

2. **주간 완성 연출**  
   7칸이 다 채워지면 “이번 주도 잘 챙겼어요” 한 줄. 보상 지급 금지.

3. **온보딩 1장**  
   “하루 한 장 / 광고는 다시 뽑을 때만 / 점세 아님”. 첫 실행 이탈을 줄인다.

### B. 수집 (콘텐츠)

4. **카드 단위 도감**  
   지금은 캐릭터 24종만 잠금 해제. `collection.cardIds`는 이미 저장되므로 캐릭터당 4장 진행률을 보여주면 반복 방문 이유가 생긴다.

5. **시즌 카드 캘린더**  
   seasonal 24장은 데이터만 있고 노출 규칙이 없다. “이번 달 시즌 테마”를 홈에 한 줄 두면 신규 콘텐츠처럼 느껴진다. 확률 가중치는 넣지 말 것.

6. **작은 행동 체크**  
   카드의 `smallAction`을 오늘 한 번 체크. 로컬 토글만. 공유·점수화하지 않음.

### C. 유입 (토스 미니앱 제약 안)

7. **카드 이미지 저장**  
   외부 SNS 딥링크 대신, 결과 카드를 이미지로 저장(Web Share / 다운로드). 심사 시 외부 브라우저 이동이 없으면 안전하다.

8. **친구에게 보여주기용 한 줄**  
   “오늘의 말랑: {moodTitle}” 복사. 링크 없이 텍스트만.

9. **앱 아이콘/브랜드**  
   `granite.config.ts` 아이콘이 placehold.co. 콘솔 아이콘을 바꾸지 않으면 스토어/토스 홈 유입에서 신뢰가 떨어진다.

### D. 일부러 미루는 것

- 연속 일수 보상, 희귀 확률 업, “더 좋은 카드” 카피 → [04-ad-flow.md](04-ad-flow.md) 금지 문구
- 외부 커뮤니티, iframe, 로그인 강제 → INTRODUCTION 원칙
- 캐릭터 36종+ 대량 추가는 일러스트 없이 체감이 약함. 먼저 기존 24종의 비주얼을 올리는 편이 낫다
