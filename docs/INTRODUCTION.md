나는 Apps in Toss(WebView) 미니앱 개발에 익숙한 시니어 프론트엔드 자바스크립트 개발자이자 기획자이다.

이번 프로젝트는 "오늘의 귀여운 뽑기"라는 Toss in App 미니앱을 초기 개발하는 것이다.
나의 핵심은, 사용자가 하루 한 번 귀여운 캐릭터 카드를 뽑고, 오늘의 응원 메시지와 함께 소소한 동기를 받는 것이다.

중요:
- 실제 Apps in Toss 콘솔에 번들 업로드 및 심사 제출을 위한 MVP가 목표이다.
- WebView 기반 Toss in App 미니앱으로 한정한다.
- TDS(Toss Design System)를 사용할 수 없는 구조이므로 직접 고려한다.
- 다크모드 기반으로 설계한다.
- Safe Area를 침범하지 않도록 한다.
- 외부 링크, iframe, 외부 서비스 자동 연결은 사용하지 않는다.
- 도박, 포인트, 쿠폰, 경품 등 재산상 이익은 절대 제공하지 않는다.
- 점세/불괘/불언처럼 보이지 않게 귀여운 응원 카드로써 만든다.
- 확률이나 뽑기박스, 사행성 강화 같은 표현은 사용하지 않는다.
- 광고는 사용자가 예상 가능한 결과 화면에서만 노출한다.
- 광고 시청 후 재뽑기는 하루 1회만 허용하고, 두 번째 카드는 오늘의 최종 카드로 강제 확정한다.
- 실제 광고 동작 전에는 mock 모드로 개발하고, 추후 Apps in Toss 광고 API로 교체 가능하도록 만든다.
- 인앱스 광고는 공식 문서 기반으로 전면 로드 후 노출하는 흐름을 고려한다.
- 현재 프로젝트 구조를 먼저 분석하고, 기존 Apps in Toss 설정이 있다면 최대한 유지하되 복잡하면 정리한다.

서비스명:
- 주요: 오늘의 귀여운 뽑기
- 보조 정보: 오늘의 응원 카드, 오늘의 말랑 카드
- 공식 appName 정보: today-cute-pick
- 이벤트 prefix: cute

MVP 핵심 기능:
1. 하루 1회 캐릭터 카드 뽑기
2. 12종 캐릭터 기반 카드 결과 출력
3. 광고 시청 후 하루 1회 추가 재뽑기
4. 재뽑기 결과는 최종 카드로 자동 확정
5. 최근 7일 카드 기록
6. 카드 컬렉션 화면
7. localStorage 기반 저장
8. 추후 Supabase 확장 가능한 구조

초기 캐릭터 12종:
1. 졸린 수달
2. 까다로운 고양이
3. 과몰입 햄스터
4. 말랑 병아리
5. 산책 강아지
6. 느긋한 거북이
7. 구름 토끼
8. 반짝 여우
9. 수줍은 판다
10. 장난꾸러기 너구리
11. 든든한 곰돌이
12. 별빛 펭귄

추후 확장:
- 24종: 계절/날씨 캐릭터 추가
- 36종: 직장/학교/취미/취업 캐릭터 추가
- 48종: 이벤트/스페셜 카드 추가
- 60종: 시즌 컬렉션 한정 카드 추가

카드 결과 구조:
각 카드에는 아래 필드가 존재한다.

type CuteCardResult = {
  cardId: string;
  characterKey: string;
  characterName: string;
  rarity: "normal" | "special" | "seasonal";
  moodTitle: string;
  message: string;
  todayPoint: string;
  smallAction: string;
  collectionTheme: string;
};

캐릭터 구조:
type CuteCharacter = {
  characterKey: string;
  characterName: string;
  baseMood: string;
  visualHint: string;
  cards: CuteCardResult[];
};

초기 데이터:
- 캐릭터 12종
- 각 캐릭터당 카드 3종 이상
- 총 36종 이상 카드
- 이미지 에셋은 아직 없을 수 있으므로, 우선 CSS 기반 카드/이모지/색상/심볼에 적합한 구조로 만든다.
- 추후 이미지 에셋이 생기면 쉽게 교체 가능하도록 characterImageKey 또는 assetPath 필드를 고려한다.

화면 구성:

1. 홈 화면
- 앱 제목: 오늘의 귀여운 뽑기
- 부제: 오늘 하루도, 오늘의 응원 카드를 뽑아보세요.
- 오늘 카드 뽑기 버튼
- 만약 오늘 카드가 확정된 경우 "뽑은 카드 보기" 버튼
- 최근 기록/컬렉션 진입 버튼

2. 카드 뽑기 화면
- 귀여운 랜덤박스 또는 카드 뒤집기 애니메이션
- "카드 뽑기" 버튼
- 1~2초 정도의 가벼운 뽑기 연출
- 과한 연출이나 무거운 애니메이션은 제외

3. 결과 화면
- 캐릭터 카드 크게 표시
- 캐릭터명
- 오늘의 무드
- 응원 메시지
- 오늘의 포인트
- 소소한 행동
- 버튼:
  - 오늘 카드 확정하기
  - 광고 보고 한 번 더 뽑기

4. 광고 후 재뽑기 흐름
- 안내 모달:
  - "광고를 시청하면 오늘 카드를 한 번 더 뽑을 수 있어요."
  - "두 번째 카드는 오늘의 최종 카드로 자동으로 확정돼요."
  - "재뽑기는 하루 1회만 가능해요."
- 광고 mock 성공 후 재뽑기 진행
- 광고 실패 또는 취소 시 기존 카드 유지
- 재뽑기 후 자동 최종 확정

5. 최종 카드 화면
- 오늘의 최종 카드 표시
- 안내: "내일 다시 카드를 뽑을 수 있어요." 안내
- 최근 7일 기록으로 이동 버튼

6. 기록 화면
- 최근 7일 카드 목록 표시
- 카드 아이템: 날짜, 캐릭터 썸네일, 캐릭터명, 무드

7. 컬렉션 화면
- 전체 캐릭터 목록 (12종 → 추후 24종)
- 획득한 캐릭터: 활성 표시
- 미획득 캐릭터: 잠금 표시

광고 흐름:
- 보상형 광고 (재뽑기): 결과 화면에서만 노출
- 배너 광고 (메인 화면 하단): 예측 가능한 위치에 항상 표시
- 광고 로드 상태: 로딩 중 / 로드 완료 / 실패 처리

기술 스택:
- React 18 + TypeScript
- Vite 5
- Tailwind CSS 3
- localStorage
- Apps in Toss SDK (광고)
