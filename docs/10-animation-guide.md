# 움직이는 캐릭터 가이드 (애니메이션 분석)

**작성일**: 2026-11-10  
**상태**: 분석 · 가이드만 있어요. **지금 앱에는 적용하지 않았어요.**  
**읽는 사람**: 초등 고학년도 이해할 수 있게 썼어요

---

## 0. 한 줄 요약

> 같은 친구를 **5번 만나면** 그 친구가 **움직이는 모습**으로 인사하게 할 수 있어요.  
> 다만 움직이는 그림은 **파일이 무거워서**, 먼저 **가볍게 만드는 방법**부터 정해야 해요.

---

## 1. 왜 "5번 만나면 움직이기"가 좋은 생각일까요?

| 이유 | 쉬운 설명 |
|------|-----------|
| 친해지는 느낌 | 처음엔 낯설고, 자주 만날수록 친해지는 것처럼 보여요 |
| 다시 오고 싶어져요 | "우리 수달, 곧 움직일 것 같은데?" 하고 기대하게 돼요 |
| 처음부터 무겁지 않아요 | 5번 만난 친구만 움직이니까 처음 앱이 가벼워요 |
| 게임 같지 않아요 | 보상이 아니라 **"친해졌어요"** 라는 이야기라서 규칙을 지켜요 |

### ⚠️ 지켜야 할 규칙

- "5번 만나면 **보상**을 줘요" ❌ → "**친해졌어요**, 인사해요" ✅
- 움직이는 카드를 **더 좋은 카드**처럼 말하지 않아요. (등급 없음)
- 못 만난 날을 혼내지 않아요. 5번은 **연속이 아니라 합계**예요. (3일 쉬어도 괜찮아요)
- 뽑기 확률은 **절대 바꾸지 않아요.**

---

## 2. 지금 앱으로 "5번"을 셀 수 있을까요?

**아직 못 세요.** 이유는 이래요.

| 지금 저장하는 것 | 문제 |
|------------------|------|
| 기록(`cute_history`) | 최근 **30일**만 저장하고, 오래된 건 지워져요 |
| 컬렉션(`cute_collection`) | "만난 적 있다/없다"만 알고 **몇 번**인지는 몰라요 |

그래서 나중에 **"몇 번 만났는지" 숫자 저장칸**을 하나 더 만들어야 해요.

```
cute_meet_counts = { "sleepy-otter": 5, "picky-cat": 2, ... }
```

- 최종 카드가 정해질 때(`finalizeTodayRecord`, `markRedrawUsed`) 해당 동물 숫자를 +1 해요.
- 재뽑기로 바뀐 날은 **최종 카드 1장만** 세요. (같은 날 두 번 세지 않기)
- 이미 쌓인 기록(최근 30일)으로 **처음 숫자를 계산**해 두면 기존 사용자도 억울하지 않아요.
- 내 폰에만 저장돼요. (서버 필요 없음)

## 3. 움직이게 만드는 방법 4가지 비교

| 방법 | 파일 크기 (한 마리) | 투명 배경 | 난이도 | 추천 |
|------|---------------------|-----------|--------|------|
| ① **CSS로 살짝 움직이기** (통통, 흔들) | **0KB** (그림 그대로) | ✅ | ⭐ 쉬움 | ⭐⭐⭐ 가장 먼저 |
| ② **움직이는 webp** | 약 80~250KB | ✅ | ⭐⭐ 보통 | ⭐⭐ |
| ③ 동영상(mp4/webm) | 약 100~400KB | ❌ (대부분) | ⭐⭐ 보통 | ⭐ 배경 때문에 어려움 |
| ④ Lottie(움직이는 그림 데이터) | 작지만 **새로 그려야 해요** | ✅ | ⭐⭐⭐ 어려움 | Grok 결과물은 못 써요 |

### ① CSS로 살짝 움직이기 (제일 가벼워요!)

지금 있는 그림 한 장을 **코드로** 움직여요. 파일이 늘지 않아요.

| 단계 | 움직임 | 느낌 |
|------|--------|------|
| 1~2번 만남 | 가만히 | 처음 만난 친구 |
| 3~4번 만남 | 천천히 위아래로 둥실 | 조금 친해짐 |
| 5번 이상 | 통통 튀고 눈 깜빡 느낌의 흔들림 | 반가워서 인사해요 |

- 장점: 용량 0, 24마리 모두 가능, 배터리도 거의 안 써요.
- 단점: 표정이 바뀌거나 팔을 흔들지는 못해요. (그림 한 장이 통째로 움직여요)

### ② 움직이는 webp (Grok 영상 → 변환)

Grok에서 **짧은 영상**을 만들고, 투명 배경 움직이는 webp 로 바꿔요.

| 항목 | 추천 값 |
|------|---------|
| 길이 | 2~3초, 반복(loop) |
| 크기 | 256×256 |
| 초당 장면 수 | 10~12 |
| 한 마리 용량 | **150KB 이하**를 목표로 |
| 24마리 합계 | 약 3~4MB (정적 그림 0.4MB의 약 10배) |

**알아둘 점**

- Grok 영상은 보통 **배경이 있는 영상**이라, 투명하게 만들려면 **흰 배경 영상**으로 만든 뒤 배경을 지우는 작업이 필요해요. (정적 그림에 쓴 방법과 같지만 장면 수만큼 반복돼서 오래 걸려요.)
- 프롬프트에 **"plain white background, static camera, loop"** 를 넣으면 지우기가 쉬워요.
- 움직임이 큰 영상일수록 용량이 커요. **작은 움직임**(눈 깜빡, 귀 쫑긋, 손 흔들기)이 가벼워요.
- 변환 도구: ffmpeg(영상→프레임) + Pillow(투명 처리·webp 저장). 24마리를 모두 하기엔 시간이 걸려요.

## 4. 용량 아끼는 방법

앱 파일(.ait)은 작을수록 빨리 열려요. 지금은 **약 0.5MB** 예요.

| 방법 | 효과 |
|------|------|
| **5번 만난 친구만 불러오기** (그때 처음 내려받기) | 안 만난 친구의 움직이는 파일은 아예 안 받아요 |
| 움직이는 파일은 **다른 폴더**에 두기 (`assets/characters/anim/`) | 정적 그림과 섞이지 않아 관리가 쉬워요 |
| 정적 그림은 **계속 앱에 포함** | 처음 열 때 빠르게 보여요 |
| 움직이는 파일 **200KB 넘으면 다시 만들기** | 합계 관리 |
| **인기 있는 6마리만 먼저** 움직이게 | 24마리 전부는 부담이 커요 |

> ⚠️ "그때 처음 내려받기"는 파일을 **앱 밖(서버/CDN)** 에 둬야 해서 **외부 연결 금지** 규칙(`01-overview.md`)과 부딪힐 수 있어요.  
> 토스 심사 규칙을 먼저 확인하고, 안 되면 **앱 안에 같이 넣는 방법**(용량 증가)을 써야 해요.

---

## 5. 추천 순서 (단계별 계획)

| 단계 | 할 일 | 용량 | 난이도 |
|------|-------|------|--------|
| **1단계** | `cute_meet_counts` 저장칸 만들기 + 도감 카드에 "N번 만났어요" 표시 | 0 | ⭐ |
| **2단계** | 3번/5번 만난 친구에게 **CSS 움직임** 적용 | 0 | ⭐ |
| **3단계** | 인기 동물 **3마리만** 움직이는 webp 시험 → 용량·속도 확인 | +0.4MB 정도 | ⭐⭐ |
| **4단계** | 문제가 없으면 나머지로 확대 | 합계 확인 필수 | ⭐⭐ |

**꼭 먼저 할 것**: 1단계. 숫자를 세지 않으면 어떤 방법도 쓸 수 없어요.  
**제일 현실적인 것**: 2단계. 파일 하나 안 늘리고도 "움직인다"는 느낌을 줄 수 있어요.

## 7. 움직이는 그림용 Grok 프롬프트 (시험용)

정적 그림 만들 때 쓴 공통 문장은 그대로 두고 **움직임 문장**만 붙여요.

```
(공통 문장) + a sleepy otter floating on its back, 
gently waving one paw and blinking slowly,
simple loop animation, static camera, plain white background
```

| 친구 | 움직임 문장 (작을수록 가벼워요) |
|------|---------------------------------|
| 🦦 수달 | slowly blinking and waving one paw |
| 🐱 고양이 | tail swishing slowly |
| 🐹 햄스터 | cheeks puffing in and out |
| 🐣 병아리 | little hop up and down |
| 🐶 강아지 | wagging tail happily |
| 🐢 거북이 | head slowly peeking out and blinking |

- 영상이 마음에 들어도 **바로 쓰지 않고** 먼저 용량부터 재 봐요.
- 150KB를 넘으면 **움직임을 줄이거나** 크기를 줄여서 다시 만들어요.
