# 오늘의 귀여운 뽑기 — 프로젝트 개요

## 서비스 소개

**오늘의 귀여운 뽑기**는 Toss in App(WebView) 미니앱으로, 사용자가 하루에 한 번 귀여운 캐릭터 카드를 뽑고 오늘의 응원 메시지와 작은 행동 제안을 받는 서비스입니다.

| 항목 | 내용 |
|------|------|
| 국문명 | 오늘의 귀여운 뽑기 |
| 영문 appName | today-cute-draw |
| 내부 prefix | cute |
| 플랫폼 | Apps in Toss (WebView 미니앱) |
| 디자인 | 라이트 모드, Tailwind CSS |
| 저장 방식 | localStorage (MVP) → Supabase (추후) |

## 핵심 원칙

- **사행성 배제**: 현금·포인트·쿠폰 등 재산상 이익 없음
- **운세 아닌 응원**: 점괘/예언 톤 없이 "귀여운 응원 카드" 톤 유지
- **Safe Area 준수**: iOS/Android Safe Area 침범 없음
- **외부 서비스 미연결**: 외부 링크, iframe, 외부 서비스 이동 없음
- **광고 사용자 예측 가능**: 결과 화면에서만 광고 노출 안내

## 화면 흐름

```
홈 → 뽑기 → 결과 → (광고) → 최종 카드
              ↓
         카드 확정
              ↓
         최종 카드 → 기록/컬렉션
```
