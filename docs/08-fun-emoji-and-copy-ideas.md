## 0. 이 문서는 뭐예요?

우리 앱은 하루에 한 번 귀여운 동물 카드를 뽑는 앱이에요.  
그런데 한 번 뽑고 "끝!" 하면 내일 또 올 이유가 약해요.

그래서 이 문서에는 **"내일도 열어 보고 싶다"** 는 마음이 들게 하는
이모지, 이모지 그림, 문구를 모아 두었어요.

비유하자면 이래요.

> 급식 메뉴가 매일 똑같으면 궁금하지 않죠?  
> 매일 조금씩 다르면 "오늘은 뭐지?" 하고 보게 돼요.  
> 우리 앱도 **매일 조금씩 다르게** 보이게 하려는 거예요.

## 1. 꼭 지켜야 하는 약속 5가지

아이디어가 아무리 재미있어도 아래 약속을 깨면 쓸 수 없어요.
([01-overview.md](01-overview.md), [04-ad-flow.md](04-ad-flow.md)에 있는 규칙이에요.)

| 약속 | 쉬운 설명 |
|------|-----------|
| 🚫 선물·포인트 없음 | 오래 왔다고 돈이나 쿠폰을 주지 않아요 |
| 🚫 "더 좋은 카드" 없음 | 모든 카드는 똑같이 소중해요. 등수가 없어요 |
| 🚫 운세·점 아님 | "오늘 운이 좋아요" 같은 말은 쓰지 않아요 |
| 🚫 혼내지 않기 | 며칠 못 와도 "실패"라고 하지 않아요 |
| ✅ 하루 한 장 | 많이 뽑게 하지 않아요. 내일을 기다리게 해요 |

> ⚠️ **지금 앱에서 고치면 좋은 문구 1개**  
> 광고를 보고 다시 뽑을 때 `"아직 더 운이 남았어요!"` 라고 나와요.  
> "운"이라는 말은 운세처럼 들릴 수 있어요.  
> 👉 추천: **"한 번 더 만나러 가요!"** 또는 **"새 친구가 오는 중이에요"**

## 3. 아이디어 자세히 보기

### ① 요일 친구 — 요일마다 다른 동물이 인사해요

지금은 요일마다 글자만 바뀌어요. 여기에 **요일 담당 동물**을 붙여요.
"월요일엔 수달이었지!" 하고 기억에 남아요.

| 요일 | 친구 | 인사말 |
|------|------|--------|
| 월 | 🦦 | 월요일이야. 하품 한 번 하고 천천히 시작하자 |
| 화 | 🐹 | 화요일! 볼에 힘 빵빵하게 넣고 출발 |
| 수 | 🐢 | 벌써 수요일. 절반이나 왔어, 잠깐 쉬어 가자 |
| 목 | 🐻 | 목요일엔 내가 뒤에서 든든하게 밀어 줄게 |
| 금 | 🦊 | 금요일이다! 오늘은 꼬리가 반짝반짝 |
| 토 | 🐶 | 토요일! 산책 가기 딱 좋은 날이야 |
| 일 | 🐑 | 일요일은 구름처럼 폭신하게 쉬는 날 |

- 넣을 곳: 홈 화면 맨 위 인사말 (`getTodayGreeting`)

### ② 시간대 인사 — 아침·낮·저녁·밤

같은 날이어도 **언제 여느냐**에 따라 말이 달라지면 살아 있는 것 같아요.

| 시간 | 이모지 | 문구 |
|------|--------|------|
| 아침 (5~11시) | 🌤️ | 좋은 아침! 오늘의 친구가 기다리고 있어요 |
| 낮 (11~17시) | 🍙 | 밥은 먹었어요? 잠깐 쉬었다 가요 |
| 저녁 (17~22시) | 🌇 | 오늘 하루 수고했어요. 카드 한 장 어때요? |
| 밤 (22~5시) | 🌙 | 아직 안 잤네요. 살금살금 한 장만 봐요 |

### ③ 자라는 새싹 — 매일 오면 쑥쑥 커요

지금은 `연속 3일째 카드를 받았어요` 라고 글자만 나와요.
숫자 옆에 **자라는 식물 이모지**를 붙이면 "키우는 재미"가 생겨요.

| 연속 일수 | 그림 | 문구 |
|-----------|------|------|
| 1일 | 🌱 | 새싹이 뿅! 나왔어요 |
| 2일 | 🌿 | 잎이 두 장이 됐어요 |
| 3일 | ☘️ | 3일째! 새싹이 기지개를 켜요 |
| 5일 | 🌷 | 꽃봉오리가 생겼어요 |
| 7일 | 🌻 | 일주일! 활짝 폈어요 |
| 14일 | 🌳 | 어느새 작은 나무가 됐어요 |
| 30일 | 🌳🐦 | 나무에 새가 놀러 왔어요 |

**하루 빠졌을 때**는 절대 혼내지 않아요.

- ❌ "연속 기록이 끊겼어요"
- ✅ "🌱 다시 만나서 반가워요. 새싹은 또 자라요"

> 왜 선물을 안 주나요?  
> 선물을 주면 "돈이 되는 앱"이 되어서 규칙을 어기게 돼요.  
> 그림이 자라는 것만 보여 줘도 충분히 뿌듯해요.

### ④ 발자국 도장 — 뽑은 친구가 도장이 돼요

7일 도장 칸에 똑같은 체크 표시 대신 **그날 뽑은 동물 이모지**를 찍어요.
일주일이 지나면 나만의 동물 줄이 완성돼요.

```
 월   화   수   목   금   토   일
 🦦   🐹   ·    🐻   🦊   ·    🎁
                              (오늘)
```

- 안 뽑은 날: 연한 점 `·` (빈칸이 눈에 띄게 슬프지 않도록)
- 오늘 아직 안 뽑음: 🎁 가 살짝 흔들려요
- 7칸을 다 채웠을 때 문구: **"이번 주 친구 7명을 다 만났어요 🎉"**

### ⑤ 흔들흔들 상자 — 열 때마다 다른 말

상자를 여는 1.2초 동안 문구를 **무작위로 하나** 보여 줘요.

- 📦 흔들흔들… 누가 들어 있을까?
- 🐾 안에서 발소리가 들려요
- 👀 상자 틈으로 누가 쳐다봐요
- 🎀 리본을 살살 푸는 중이에요
- 💤 쉿, 자고 있을지도 몰라요

이모지 그림으로 순서를 보여 줄 수도 있어요.

```
🎁  →  🎁💨  →  ✨📦✨  →  🐥
가만히   흔들흔들    반짝!     짜잔
```

### ⑥ 내일 예고 — 다음 화가 궁금한 만화처럼

지금 마지막 화면에는 `🌙 내일 새로운 카드를 뽑을 수 있어요` 한 가지만 나와요.
만화가 "다음 화에 계속!" 하고 끝나면 궁금하죠? 그 느낌을 줘요.

- 🌙 내일은 누가 찾아올까요?
- 🚪 내일 아침, 새 친구가 문을 두드려요
- 💌 내일 도착할 응원을 포장하는 중이에요
- 🐾 아직 못 만난 친구가 N명 있어요 (N = 24 − 모은 수)
- 😴 친구들은 자러 갔어요. 내일 또 만나요

마지막 줄의 "N명"은 **도감 숫자와 이어져서** 특히 효과가 좋아요.

### ⑦ 도감 수수께끼 — ❓ 대신 힌트

아직 못 만난 친구는 지금 `❓` 로만 보여요.
여기에 **한 줄 힌트**를 주면 "누굴까?" 하고 맞혀 보고 싶어져요.

| 친구 | 수수께끼 힌트 |
|------|----------------|
| 🦦 | 물 위에 누워서 낮잠 자는 걸 좋아해요 |
| 🐱 | 새침하지만 사실은 관심이 많아요 |
| 🐹 | 볼주머니에 간식을 가득 넣어요 |
| 🐣 | 노랗고 말랑말랑, 삐약 소리를 내요 |
| 🐶 | "산책"이라는 말만 들어도 꼬리가 흔들려요 |
| 🐢 | 느리지만 끝까지 가요. 집을 등에 메고 다녀요 |
| 🐰 | 귀가 길고 구름처럼 폭신해요 |
| 🦊 | 꼬리가 풍성하고 눈이 반짝여요 |
| 🐼 | 흰색과 검은색, 대나무를 좋아해요 |
| 🦝 | 눈가에 가면을 쓴 장난꾸러기예요 |
| 🐻 | 꿀을 좋아하는 든든한 친구예요 |
| 🐧 | 날지는 못해도 얼음 위를 뒤뚱뒤뚱 걸어요 |
| 🐑 | 온몸이 솜사탕 같은 털로 덮여 있어요 |
| 🐙 | 다리가 여덟 개! 바닷속 재주꾼이에요 |
| 🐸 | 비 오는 날 폴짝폴짝 신이 나요 |
| 🐨 | 나무를 꼭 껴안고 하루 종일 쉬어요 |
| 🐋 | 바다에서 가장 큰 몸으로 물을 뿜어요 |
| 🐦 | 아침마다 제일 먼저 노래해요 |
| 🦉 | 밤에 눈을 크게 뜨고 생각에 잠겨요 |
| 🦁 | 멋진 갈기를 가진 용감한 친구예요 |
| 🐘 | 코가 길고 귀가 커다래요 |
| 🦋 | 꽃밭을 팔랑팔랑 날아다녀요 |
| 🦌 | 머리에 작은 뿔이 있고 숲에 살아요 |
| 🐷 | 분홍색 코로 킁킁, 늘 기분이 좋아요 |

- 힌트는 **도감에서 ❓ 칸을 눌렀을 때** 보여 줘요
- 뽑을 확률은 바꾸지 않아요. 힌트만 보여 주는 거예요

### ⑧ 카드 종류 이름표 — 귀여운 이름으로

카드에는 세 종류가 있어요 (`normal`, `special`, `seasonal`).
이 말은 "보통 / 특별"처럼 **등수**처럼 들릴 수 있어요.
등수가 아니라 **분위기**로 느껴지게 이름을 바꿔요.

| 지금 이름 | 새 이름표 | 뜻 |
|-----------|-----------|----|
| normal | 🌼 매일 카드 | 날마다 만나는 포근한 카드 |
| special | 💫 속마음 카드 | 친구의 숨은 마음이 담긴 카드 |
| seasonal | 🍂 계절 카드 | 봄·여름·가을·겨울 이야기 카드 |

"희귀", "레어", "대박" 같은 말은 쓰지 않아요.

### ⑨ 작은 행동 체크 — "나 했어요!" 꾹

카드마다 `smallAction` (작은 행동 제안)이 있어요. 예: "물 한 잔 마시기".
이걸 했을 때 누를 수 있는 **말랑한 버튼**을 줘요.

- 누르기 전: `🤍 해 볼게요`
- 누른 뒤: `💛 해냈어요!` + 동물이 살짝 통통 튀어요

누른 뒤 나오는 칭찬은 무작위로 하나.

- 👏 우와, 진짜 했네요!
- 🫶 작은 일이 제일 대단해요
- 🌟 오늘의 나, 조금 멋졌어요

점수나 순위는 매기지 않아요. 내 휴대폰에만 기록돼요.

### ⑩ 계절 한 줄 — 달마다 바뀌는 인사

| 달 | 이모지 | 문구 |
|----|--------|------|
| 3~5월 | 🌸 | 꽃잎이 날리는 날, 친구도 들떠 있어요 |
| 6~8월 | 🍉 | 더운 날엔 수박처럼 시원한 응원 |
| 9~11월 | 🍂 | 낙엽 밟는 소리처럼 바삭한 하루 |
| 12~2월 | ⛄ | 추운 날엔 따끈한 카드 한 장 |

특별한 날에는 한 줄만 살짝 바꿔요.

- 🎂 처음 뽑은 지 100일째: "우리 만난 지 100일이에요"
- 🎄 12월 25일: "오늘은 친구들도 빨간 목도리를 했어요"
- 🎍 1월 1일: "새해 첫 카드예요. 천천히 열어 봐요"

## 4. 이모지 그림 모음 (그대로 써도 되는 것)

진짜 그림(일러스트)이 생기기 전까지는 **이모지를 붙여서 작은 그림**을 만들 수 있어요.
파일이 필요 없어서 앱이 무거워지지 않아요.

| 쓰는 곳 | 이모지 그림 | 느낌 |
|---------|-------------|------|
| 아직 안 뽑은 홈 | 🎁💤 | 상자가 자고 있어요 |
| 뽑기 버튼 옆 | 👉🎁 | 여기를 눌러요 |
| 카드 확정 | 📮💌 | 오늘의 카드를 우체통에 쏙 |
| 도감 다 모음 | 🎉🐾🎉 | 모두 만났어요 |
| 기록이 비었을 때 | 📖🐾 | 아직 빈 일기장이에요 |
| 밤 인사 | 🌙💤🐑 | 양이 자러 가요 |
| 광고 기다리는 중 | 🍿⏳ | 잠깐만 기다려요 |

**빈 화면 문구**도 같이 바꾸면 좋아요.

- 기록이 없을 때: "📖 아직 빈 일기장이에요. 첫 장을 채워 볼까요?"
- 도감이 0명일 때: "🐾 발자국만 보여요. 누가 지나갔을까요?"

## 5. 말투 규칙 (문구를 새로 지을 때)

| 이렇게 써요 ✅ | 이렇게는 안 써요 ❌ | 이유 |
|----------------|---------------------|------|
| 친구를 만났어요 | 카드를 획득했어요 | 게임 아이템처럼 들려요 |
| 내일 또 만나요 | 내일 안 오면 끊겨요 | 겁주면 안 돼요 |
| 다시 뽑기 | 더 좋은 카드 받기 | 카드에 등수가 없어요 |
| 오늘의 응원 | 오늘의 운세 | 점이 아니에요 |
| 7일 다 만났어요 | 7일 출석 보상 | 보상이 없어요 |

짧게 쓰는 요령 3가지.

1. 한 줄에 **20자 안쪽**으로 써요. 휴대폰 화면은 좁아요.
2. 이모지는 한 줄에 **1~2개**만. 많으면 정신없어요.
3. **동물이 직접 말하는 것처럼** 쓰면 더 귀여워요.

## 6. 어디에 넣으면 되나요? (나중에 코드 고칠 사람용)

지금은 코드를 고치지 않았어요. 나중에 넣을 때 참고할 위치예요.

| 아이디어 | 고칠 파일 | 새 저장 데이터 |
|----------|-----------|----------------|
| ① 요일 친구, ② 시간대, ⑩ 계절 | `utils/engagement.ts` | 없음 |
| ③ 자라는 새싹 | `screens/HomeScreen.tsx` | 없음 (이미 있는 연속 일수 사용) |
| ④ 발자국 도장 | `components/WeekStampRow.tsx` | 없음 (기록에 동물 정보가 있음) |
| ⑤ 상자 문구 | `screens/DrawScreen.tsx`, `components/DrawBox.tsx` | 없음 |
| ⑥ 내일 예고 | `screens/FinalCardScreen.tsx` | 없음 |
| ⑦ 도감 힌트 | `data/characters.ts`, `components/CharacterCollection.tsx` | 캐릭터마다 힌트 한 줄 추가 |
| ⑧ 이름표 | `components/CuteCard.tsx` | 없음 |
| ⑨ 행동 체크 | `storage/cuteDrawStorage.ts` 외 | 오늘 기록에 "했어요" 표시 1개 |

대부분 **새로 저장할 게 없어서** 안전하게 넣을 수 있어요.

### 추천 순서

| 순서 | 넣을 것 | 이유 |
|------|---------|------|
| 1단계 | ① 요일 친구 + ③ 새싹 + ⑥ 내일 예고 + "운" 문구 고치기 | 글자만 바꾸면 돼요 |
| 2단계 | ④ 발자국 도장 + ⑤ 상자 문구 + ⑧ 이름표 | 화면이 조금 바뀌어요 |
| 3단계 | ⑦ 도감 힌트 + ⑨ 행동 체크 | 새 데이터가 필요해요 |
